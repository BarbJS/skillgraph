# Prompts da CrewAI

Os arquivos desta pasta são o contrato de comportamento dos agentes. Eles são carregados pelo orquestrador local e versionados no repositório; não é necessário criar cada agente no site do CrewAI.

Cada agente deve receber e produzir JSON validado. O LLM não pode substituir validação backend, allowlist de ferramentas ou revisão humana.
