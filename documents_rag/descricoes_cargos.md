# Descrições de Cargos e Competências

## Versão: 3.0
## Última atualização: 20 de agosto de 2026
## Responsável: RH e Gestores de Área

---

## 1. Objetivo

Esta descrição é a fonte de referência para requisitos de cargos, níveis de competência, faixas salariais e caminhos de carreira. As faixas apresentadas são intervalos do cargo, não salários individuais. Diagnósticos e recomendações devem comparar os dados estruturados de competências com os requisitos desta descrição e devem ser revisados por gestores e RH.

Este documento descreve os cargos da NexaTech, incluindo:

- Título e departamento.
- Nível de senioridade.
- Competências obrigatórias e desejáveis.
- Faixa salarial.
- Caminhos de carreira.

---

## 2. Estrutura de Níveis

| Nível | Descrição |
|---------|-----------|
| Estágio | Aprendizado inicial, supervisão constante. |
| Júnior | Execução com orientação, autonomia limitada. |
| Pleno | Execução autônoma, resolve problemas complexos. |
| Sênior | Referência técnica, mentoria, decisões estratégicas. |
| Especialista | Profundidade técnica extrema, inovação. |
| Liderança | Gestão de equipes, responsabilidades estratégicas. |

## 4. Níveis de Competência

| Nível | Descrição |
|---------|-----------|
| 1 | Básico: compreende conceitos, precisa de supervisão. |
| 2 | Intermediário: executa tarefas rotineiras com autonomia. |
| 3 | Avançado: resolve problemas complexos, orienta outros. |
| 4 | Especialista: referência na área, inova e lidera. |
| 5 | Expert: reconhecido internamente e externamente, define diretrizes. |
